- **D-17 Theme-named selectors for the two rules that must beat an inline style** — S5 had to make win98's bevels and its white selected-row ink actually paint. Both fixes need `!important` (every carrier writes `border`/`boxShadow`/`color` inline), and an `!important` rule **cannot be made inert by its token's value**: a `none`/`inherit` substitution is invalid at computed-value time, which computes to `unset` and *erases* the default theme's own inline paint instead of leaving it alone. The space-toggle trick does not help for the same reason. So the gate had to be the **selector**. *Implemented (S5)*: three rules in `theme.css` name `[data-theme="win98"]` — the first theme-named behaviour rule in the file (every other one is a token block). A new skin opts in by adding its name to those selector lists; nothing else about adding a skin changes. The alternative the brief offered — a `data-bevel` attribute stamped by `theme.js` — was not taken: the store would have to carry a hard-coded list of bevelled themes (the same duplication, in a second file), or read a custom property off a `.jn-v2` element that may not be mounted when `apply()` runs at boot. **needs decision** — if the project would rather pay for the attribute, it is one map in `theme.js`, one prop in `V2App`, one line in `index.html`'s boot script, and the three selectors become `[data-bevel]` / `[data-rowink]`.
  - *scope of the ink hook, deliberately narrow*: `.v2-rowink` marks the **reading content** of a picked row (title, company, meta run, the ✦ tailored link; in Applications the title, company and the days figure). A blanket `*:not(svg *)` was rejected — the same row carries a status badge on its own light ground, a ScoreRing chip, a "+N reports" pin and (Applications) a ✉ hidden behind `color:transparent`, and every one of those breaks when the subtree is flattened to one ink. **Left unfixed and visible in win98**: the Feed row's three rail glyph cells (♥ / ✕ / ⋯, `--accent` / `--text-2` / `--muted`) sit on the navy fill at roughly 1.5:1 while a row is selected.
